### 🗺️ Structure Matrix

```text
DSA-in-C/
├── 📁 Arrays/        ─── Linear / Binary Search • ADT Operations
├── 📁 LinkedList/    ─── Singly • Doubly • Circular
├── 📁 Stack/         ─── Array Stack • Pointer Stack
├── 📁 Queue/         ─── Circular • Priority Queue
├── 📁 Trees/         ─── BST • Traversals • Node Deletion
├── 📁 Graphs/        ─── DFS • BFS • Adjacency Matrices
└── 📁 Sorting/       ─── Quick • Merge • Heap • Bubble

```

### ⏱️ Complexity & Memory Radar

| Structure | Access | Search | Insertion | Deletion | Memory Type |
| --- | --- | --- | --- | --- | --- |
| **Array** | `O(1)` | `O(n)` | `O(n)` | `O(n)` | Contiguous Stack/Heap |
| **Linked List** | `O(n)` | `O(n)` | `O(1)` | `O(1)` | Dynamic Heap Nodes |
| **Stack / Queue** | `O(n)` | `O(n)` | `O(1)` | `O(1)` | LIFO / FIFO Buffer |
| **BST (Average)** | `O(log n)` | `O(log n)` | `O(log n)` | `O(log n)` | Pointer Tree |
